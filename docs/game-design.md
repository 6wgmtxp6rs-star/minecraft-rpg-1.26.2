# Game Design Document

## Title
Minecraft RPG 26.2

## Core inspiration
This project is inspired by the fantasy progression, high-difficulty combat, loot grind, class identity, and exploration loop that made Cisco-style fantasy RPG packs memorable, but the final project is built as a fresh original system.

## Major pillars

### 1. Progression
- Level-based character progression
- Skill points earned by combat, exploration, and quest completion
- Unlockable passive bonuses and active abilities
- Rare loot and equipment tiers

### 2. Fantasy classes
Each class has a role and a skill tree.

#### Knight
- Role: Frontline tank
- Key stats: Strength, Defense, Vitality
- Abilities: Shield bash, guard stance, stamina burst

#### Mage
- Role: Burst DPS and battlefield control
- Key stats: Intellect, Focus, Mana
- Abilities: Arcane burst, shield, elemental spells

#### Ranger
- Role: Mobility and ranged combat
- Key stats: Agility, Precision, Stealth
- Abilities: Volley, tracking, trap deployment

#### Rogue
- Role: Dexterity and burst attacks
- Key stats: Speed, Critical chance, Evasion
- Abilities: Dash, ambush, poison strikes

#### Paladin
- Role: Support and hybrid melee magic
- Key stats: Faith, Defense, Resolve
- Abilities: Radiant heal, holy strike, aura

### 3. Combat system
- Weapon skill scaling
- Armor encumbrance affecting mobility
- Dodge window and stamina use
- Critical hits and combo chains
- Boss phases and mechanics

### 4. World and exploration
- Heroic biomes and dungeon structures
- Ancient ruins and boss chambers
- New dimensions or realm variants
- Quests that reveal lore and unlock zones

### 5. Kingdom building
- Town construction
- NPC recruitment
- Defense events against raids
- Resource management and upgrades

## Core loop

1. Explore
2. Gather resources
3. Fight enemies and bosses
4. Earn loot and XP
5. Unlock abilities and class bonuses
6. Return to town to upgrade gear and support structures
7. Progress into harder zones

## Start state
The player begins in a small village with:
- a starter weapon
- minimal gear
- a basic quest log
- access to a nearby dungeon

## Long-term goals
- Defeat the first dungeon boss
- Unlock class specializations
- Build a class-based town
- Explore corrupted regions and bosses
- Complete the main campaign or guild questline

## Success metrics
A successful version of the RPG should include:
- unique classes with meaningful progression
- a quest-driven world
- dynamic combat and loot variety
- towns and kingdom progression
- satisfying endgame challenge
